Check the current status of a swap intent. The response includes the intent's lifecycle state, the related transactions, and additional metadata.

```http
GET /affiliate/v1/swaps/intents/{intent_id}
```

## Swap details

The response includes transaction hashes, amounts, USD values, and affiliate fees. `swap_metadata` is `null` before an execution record exists. Its `id` identifies the swap record.

## Status only

```http
GET /affiliate/v1/intents/{intent_id}/status
```

This endpoint returns the status without the swap details. `decline_details` appears only when the intent has decline information.

```json
{
	"status": "Declined",
	"decline_details": {
		"error_code": 1,
		"message": "quote expired"
	}
}
```

## Statuses

`status` represents the overall progress of the swap, combining intent and swap state.

| Status | Description |
| --- | --- |
| `Initiated` | The intent has been created but no approval has been added yet. |
| `ApprovalAdded` | The API has accepted the user's signed approval. |
| `Accepted` | A resolver has accepted the intent and is ready to execute. |
| `Declined` | The resolver declined the intent. |
| `UserDeposited` | The source-chain deposit has been confirmed. |
| `Fulfilled` | The user has received the target token on the destination network. |
| `Expired` | The swap passed its fulfillment deadline. |
| `RefundRequested` | A refund has been requested for this intent. |
| `Refunded` | Tokens have been refunded to the user. |
| `AwaitingBroadcast` | A broadcast intent is waiting for the user to fund it and report the transaction. |
| `Lapsed` | The intent deadline passed before approval handling or user funding completed. |

## Fee records

`fees` contains the intent's affiliate fee records. Each record includes `intent_id`, `sub_affiliate_id`, `fee_bps`, `network_id`, `token`, `fee_amount_lots`, `fee_amount_decimals`, and `status`. Fee status is `Created`, `ToSettle`, `Cancelled`, or `Settled`.

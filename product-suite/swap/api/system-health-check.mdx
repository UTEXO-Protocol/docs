---
title: "System liveness"
description: "Check whether the affiliate API process responds to requests."
sidebarTitle: "Health check"
---

```http
GET /affiliate/v1/system/live
```

The endpoint returns HTTP `200` with an empty body after affiliate authentication. It checks that the API process responds. It does not check database, queue, or blockchain-provider readiness.

```bash
curl -i https://stage.api.swap.utexo.com/affiliate/v1/system/live \
	-H "X-API-Key: $UTEXO_SWAP_API_KEY"
```

A missing or malformed header returns HTTP `400` with error code `14`. An inactive API key returns HTTP `401` with code `53`. Other authentication or service failures use the [error response format](/product-suite/swap/development/errors).

`GET /v1/system/live` is the resolver endpoint and requires a resolver API key.

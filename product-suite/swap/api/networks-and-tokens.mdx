## List networks

The response lists networks visible to the authenticated affiliate. The optional `token` query parameter filters networks by token, for example `?token=USDC`.

```http
GET /affiliate/v1/networks
```

### Response example

```json
[
	{
		"id": 1,
		"name": "Ethereum",
		"type": "EVM",
		"supports_optimized_swap": false,
		"icon_url": "https://raw.githubusercontent.com/trustwallet/assets/master/blockchains/ethereum/info/logo.png",
		"supports_custom_tokens": false
	}
]
```

<Info>
  If `supports_custom_tokens` is `true` for a network, users can swap custom tokens on that network. In that case the tokens returned for the network are popular tokens, not a complete list of supported tokens.
</Info>

## List tokens

Retrieve a paginated list of tokens supported across all networks. Supports pagination, filtering by network, and searching by token symbol, name, or contract address.

```http
GET /affiliate/v1/tokens
```

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `limit` | integer | No | Page size. Default `20`, capped by the server configuration. |
| `offset` | integer | No | Number of tokens to skip. Default `0`. |
| `q` | string | No | Search query for token symbol, token name, or contract address |
| `network_id` | integer | No | Filter tokens by network |

### Response example

```json
{
	"data": [
		{
			"network_id": 1,
			"name": "Tether USD",
			"contract_address": "0xdac17f958d2ee523a2206206994597c13d831ec7",
			"symbol": "USDT",
			"icon_url": "https://raw.githubusercontent.com/trustwallet/assets/master/blockchains/ethereum/assets/0xdAC17F958D2ee523a2206206994597C13D831ec7/logo.png",
			"wrapped_token_address": null
		}
	],
	"pagination": {
		"limit": 10,
		"offset": 0,
		"pages": 50,
		"total": 500
	}
}
```

<Info>
  If a token has a non-empty `wrapped_token_address`, it must be wrapped before use. See [Wrap Native Tokens](/product-suite/swap/on-chain-helpers/wrap-native-tokens).
</Info>

## Example

```ts
const BASE_URL = "https://stage.api.swap.utexo.com/affiliate";
const headers = { "X-API-Key": process.env.UTEXO_SWAP_API_KEY! };

const networks = await fetch(`${BASE_URL}/v1/networks`, { headers }).then((r) => r.json());
const tokens = await fetch(`${BASE_URL}/v1/tokens?network_id=1&q=USDT&limit=10`, { headers }).then((r) => r.json());
```

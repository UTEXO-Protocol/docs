The quote's `deposit_type` determines how source funds are held. Escrowed and direct deposits have different protections.

## Escrowed deposits

An escrowed standard swap locks source funds under chain-specific settlement rules. After Utexo verifies destination fulfillment, it reveals the secret that permits the resolver to claim the source funds.

| Network | Source settlement |
| --- | --- |
| EVM or Tron | An escrow proxy for the swap. |
| Solana | A shared vault holds tokens. An `EscrowCheck` PDA records the order and its withdrawal conditions. |
| Bitcoin | A Taproot HTLC output contains a secret-based claim path and refund paths. |

The source deposit, destination fulfillment, and source withdrawal are separate on-chain transactions. A refund requires an on-chain transaction. A standard cross-chain swap does not revert both chains as one atomic transaction.

## Direct deposits

A `direct` deposit transfers source funds to the resolver without the source-chain escrow protection described above. Quote selection can return this deposit type for a permit-flow affiliate when the resolver supports direct deposits.

The affiliate does not select `deposit_type` in the quote request. The returned quote records the selected deposit type.

## Optimized same-chain swaps

An optimized swap exchanges the source and destination tokens in one atomic transaction. The quote identifies this path with `swap_type: "optimized"`.

## Refunds

Escrowed swaps use deadlines to bound the resolver's claim and the refund path. The intent supplies `refund_address` and `deadline_secs`. A fast refund uses resolver and protocol cooperation. A timelock refund becomes available after its deadline.

For Bitcoin and RGB, the protocol key controls the timelock refund leaf. The user's Bitcoin key does not spend that leaf directly. RGB refunds also require a valid consignment that moves the allocation.

The chain-specific references describe [EVM and Tron settlement](/product-suite/swap/resolver-integration/evm-tron-settlement), [Solana settlement](/product-suite/swap/resolver-integration/solana-settlement), and [Bitcoin settlement](/product-suite/swap/resolver-integration/bitcoin-settlement).

<Warning>
  `@utexo/rgb-sdk` is **archived**. The [source repository](https://github.com/UTEXO-Protocol/rgb-sdk) is read-only; its last committed package version is `1.0.0-beta.9`. Do not start new Node.js integrations on this package.
</Warning>

For new Node.js (and Bare / React Native worklet) integrations, use [`@utexo/wdk-rgb-lightning`](/sdk/wdk-rgb-lightning). It is the current WDK module for RGB-over-Lightning: channels, invoices, payments, HODL invoices, LSP, APay, and VSS.

| Instead of | Use |
|---|---|
| `@utexo/rgb-sdk` (Node.js, archived) | [`@utexo/wdk-rgb-lightning`](/sdk/wdk-rgb-lightning) |
| Browser | [`@utexo/rgb-sdk-web`](/sdk/web-sdk) |
| iOS / Android | [`@utexo/rgb-sdk-rn`](/sdk/react-native-sdk) |
| On-chain RGB issuance (WDK) | [`@utexo/wdk-wallet-rgb`](/sdk/wdk-wallet-rgb) |

Existing applications still on `@utexo/rgb-sdk` can follow the [legacy Node.js Quickstart](/getting-started/quickstart/node-js) for the last committed API. New work should follow the [wdk-rgb-lightning reference](/sdk/wdk-rgb-lightning).
